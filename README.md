# Ithan NY — Dossier oficial

Dossier digital profesional de Ithan NY para marcas, productoras, medios y
eventos. La experiencia reúne biografía, música, trayectoria, cifras de
audiencia, enlaces oficiales y contacto profesional en una estética urbana
animada.

## Sitio publicado

[ithan-new-york.vercel.app](https://ithan-new-york.vercel.app)

## Características

- Hero audiovisual con reproducción limitada a los primeros 2,5 segundos.
- Pre-save animado del álbum **Placeres**.
- Recorrido artístico desde **Con Roni** hasta **Suéltala**.
- Cifras oficiales de Spotify y YouTube.
- Enlaces oficiales de Ithan NY.
- Formulario de contacto para oportunidades profesionales.
- Identidad de Flow New York y logo oficial de D!STR!KT.
- Diseño adaptable para escritorio y dispositivos móviles.

## Desarrollo

Requiere Node.js 22 o superior.

```bash
npm install
npx next dev
```

Para validar la versión de producción:

```bash
npx next build
```

## Despliegue

El proyecto está configurado para Next.js en Vercel mediante `vercel.json`.
